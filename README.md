# 🏓 탁구 풀리그 대진표 & 스코어보드 (Pingpong Club Scoreboard)

어르신들도 보기 쉬운 시니어 친화적 디자인, 모바일 맞춤형 반응형 UI(선수별 아코디언 대진표 & 카드형 순위표), 여러 스마트폰/태블릿 간 실시간 점수 공동 입력(WebRTC P2P 동기화), 다중 동호회 관리, 모임 날짜별 히스토리 기능, 통산 누적 순위표를 제공하는 **탁구 풀리그(Round-Robin) 대진표 & 스코어보드 설치형 웹앱(PWA)**입니다.

- **🌐 웹앱 바로 실행 & 앱 설치 주소**: **[https://swmin.github.io/pingpong-club/](https://swmin.github.io/pingpong-club/)**
  - 스마트폰(갤럭시 S25 등)이나 태블릿(갤럭시 탭 S9 등)에서 위 주소로 접속해 우측 상단 파란색 **`[📲 앱 설치]`** 버튼을 누르면 바탕화면과 앱 서랍에 **`탁구스코어`** 앱이 설치되어 일반 앱처럼 전체 화면 및 오프라인으로 사용할 수 있습니다.
  - 인터넷 연결이 없는 환경에서도 단일 HTML 파일(`pingpong-club-scoreboard.html`) 하나만 있으면 모든 기기에서 100% 오프라인으로 단독 실행할 수도 있습니다.

## 1. 📥 코드 다운로드, 빌드 및 배포 방법 (Build & Deploy Guide)

### 1) Git 저장소 복제 (Clone)
```bash
# 최신 버전 코드 내려받기
git clone https://github.com/swmin/pingpong-club.git
cd pingpong-club

# 특정 버전 태그(예: ver.0.8) 코드로 받아 오실 경우
git clone -b ver.0.8 https://github.com/swmin/pingpong-club.git
```

### 2) 의존성 패키지 설치
```bash
npm install
```

### 3) 로컬 개발 서버 실행
```bash
npm run dev
```
- 실행 후 웹 브라우저에서 `http://localhost:5173/` 접속하여 실시간 개발 화면 확인.

### 4) PWA 및 단일 HTML 파일 빌드 (`dist/` & `pingpong-club-scoreboard.html`)
```bash
npm run build
```
- 빌드 실행 시 PWA 배포용 `dist/` 폴더(`index.html`, `manifest.webmanifest`, `sw.js`, 앱 아이콘 일체)가 생성되며, 동시에 루트 경로의 단일 실행 파일 `pingpong-club-scoreboard.html`도 자동으로 최신화됩니다.

### 5) GitHub Pages 자동 배포 설정 (최초 1회)
- GitHub 저장소의 **`Settings` ➔ `Pages` ➔ `Build and deployment` ➔ `Source`**를 **`GitHub Actions`**로 설정하면, `main` 브랜치에 `git push`할 때마다 `.github/workflows/deploy.yml` 워크플로가 자동 실행되어 `https://swmin.github.io/pingpong-club/` 웹앱이 최신 버전으로 자동 업데이트됩니다.

## 2. 🏆 주요 기능 (Key Features)

1. **시니어 친화적 웹 UI & 글자 크기 조절**
   - 어르신들도 시원하게 보실 수 있는 고대비 다크 모드 및 시니어 스포티 디자인.
   - 상단 제어바에서 **`[보통 (1.0)]`**, **`[크게 (1.2)]`** 글자 크기 조절 지원 및 음성 안내(TTS) 켜기/끄기.

2. **가로 스크롤 없는 모바일 친화적 반응형 UI**
   - **모바일 카드형 순위표**: 스마트폰 등 좁은 화면(`700px` 이하)에서는 좌우 스크롤 없이 한눈에 들어오는 2줄 요약 카드로 순위를 표시하며, 동률 산정 사유 터치 펼치기 및 통산 순위 정렬 기준 드롭다운을 지원합니다.
   - **선수별 아코디언 대진표 (`👤 선수별 보기`)**: 출전 선수가 많아도 가로 스크롤 없이 내 이름을 터치해 상대 전적과 남은 경기를 확인하고 즉시 점수를 입력할 수 있습니다.
   - 넓은 화면(태블릿 가로 모드 및 PC)에서는 기존 전체 표 및 격자 대진표 레이아웃으로 자동 전환됩니다.

3. **다중 동호회(100+개) & 모임 날짜별 히스토리 관리**
   - **동호회 관리**: 100개 이상의 동호회를 각각 독립적으로 생성 및 선택 관리.
   - **모임 히스토리(날짜 페이지)**: 과거 모임 결과를 보존하면서 새 모임 날짜 페이지를 계속 추가 생성 가능.

4. **3개 카테고리 기반 선수 관리 명단 시스템**
   - **`[🏢 동호회 선수]`**, **`[⭐ Guest 선수]`**, **`[⚙️ 선수 추가/관리]`** 3개 메뉴 구분.
   - 클릭 한 번으로 오늘의 참가자 지정.
   - 당일 부수(선수부, 1부~13부) 수정 시 과거 모임 기록의 부수는 안전하게 유지되는 모임별 독립 부수 보존.

5. **실시간 풀리그 대진표 (3가지 뷰 실시간 연동) & 경기 기록 보존**
   - **`👤 선수별 보기`**, **`📋 경기 순서별`**, **`🏁 격자표 (종이 대진표)`** 3가지 뷰를 지원하며, 어느 화면에서 점수를 입력하거나 수정하더라도 모든 뷰에 100% 실시간으로 연동됩니다.
   - 게임 운영 도중 참가 선수가 추가되거나 변경되어도 **이미 입력된 기존 승패 및 세트 점수는 삭제되지 않고 유지**됩니다.

6. **실시간 순위표 & 동호회 통산 누적 순위표 (가로 탭 UX)**
   - **`🏆 오늘 모임 실시간 순위표`**: 오늘 모임 경기 결과 기반 승수, 승자승, 세트 득실율, 순위 결정 사유 실시간 계산.
   - **`📊 동호회 통산 누적 순위표`**: 해당 동호회 안에서만 전체 모임 기록을 합산한 통산 누적 순위표 제공 (참석수, 승률, 다승, 승점, 세트득실 기준 정렬 지원 및 마지막 모임 날짜 명시).

7. **결과저장 (화면 잘림 없는 고화질 PNG 전체 이미지 자동 다운로드)**
   - 스마트폰 세로/가로 모드나 현재 선택된 대진표 탭에 상관없이, **`[결과저장]`** 클릭 시 웹페이지 전체(전체 격자 대진표 + 전체 순위표)를 인식하여 잘림 없는 고화질 PNG 이미지로 생성합니다.
   - 통산 누적 순위표 탭 내 전용 **`[결과저장]`** 클릭 시 통산 누적 순위표 전체 표를 독립 PNG 이미지로 저장합니다.
   - 파일명에 저장 시각(`_시분초`)이 자동으로 부여되어 중복 덮어쓰기 없이 기기의 `Download` 폴더에 즉시 다운로드되며, 완료 시 안내 팝업이 표시됩니다.

8. **데이터 내장 HTML 내보내기 & JSON 백업/복원 (100% 하위 호환)**
   - **`[📂 데이터 포함 HTML 저장]`**: 브라우저에 누적된 데이터 전체가 코드 내부에 포함된 HTML 파일 저장. 원드라이브(OneDrive) 등으로 공유 후 휴대폰/갤럭시 탭에서 열면 복원 절차 없이 100% 모임 히스토리 실행.
   - **`[백업 (.json)]` / `[복원 (.json)]`**: 전체 모임 데이터를 JSON 백업 파일로 저장 및 복원 (이전 버전에서 저장한 백업 JSON 파일도 완벽 호환).

9. **📡 함께 입력하기 (서버 없는 WebRTC P2P 실시간 동기화)**
   - **별도 서버 구축 없이 기기 간 직접 연동**: 처음 연결(악수)할 때만 공개 WebRTC 중계소(PeerJS)와 다중 STUN 서버(Google·Cloudflare)를 거치고, 이후 모든 점수와 명단 데이터는 기기 대 기기(P2P)로 직접 주고받습니다.
   - **4G/5G 모바일 데이터 & Wi-Fi 완벽 호환**: 모든 폰이 4G/5G(LTE/5G)를 쓰거나, 태블릿은 Wi-Fi·휴대폰은 4G/5G를 쓰는 등 서로 다른 통신망이 섞여 있어도 실시간으로 동기화됩니다.
   - **간편한 방 입장 (4자리 숫자 코드 & QR코드 스캔)**: 방장이 **`[함께 입력하기] → [방 만들기]`**를 누르면 생성되는 **4자리 방 번호**를 입력하거나 **카메라 QR 스캔**으로 즉시 참가할 수 있습니다. 연결 즉시 방장의 오늘 모임 선수 명단과 대진표가 참가자 폰에 자동 복제됩니다.
   - **방장 / 관리자(`👑`) / 일반 도우미 권한 분리**:
     - **일반 도우미**: 실수로 선수를 삭제하거나 초기화하는 사고를 막기 위해 **'점수 입력 및 조회'만 가능**하며 선수 명단 메뉴는 잠깁니다.
     - **관리자 권한 부여 (2가지 방법)**: ① 방장이 접속자 목록에서 **`[👑 관리자 주기]`** 버튼을 눌러주거나, ② 도우미가 방장 화면에 표시된 **4자리 관리자 번호**를 입력해 잠금을 해제하면 방장과 동일하게 선수 추가·제외·부수 변경이 가능하며 변경된 대진표가 전원에게 즉시 반영됩니다.
   - **동시 입력 충돌 방지 & 화면 꺼짐 자동 복구**:
     - 여러 코트에서 동시에 점수를 입력해도 개별 경기(`matchId`)의 저장 시각(`updatedAt`) 기준으로 최신 점수만 스마트 병합되어 다른 경기 점수가 덮어써지지 않습니다.
     - 경기 중 휴대폰 화면이 꺼졌다가 다시 켜지면 자동으로 재연결되며, 화면이 꺼져 있던 동안 입력된 점수도 한 번에 맞춰집니다.

10. **📲 설치형 웹앱(PWA) & 회원 앱 설치 QR코드 공유**
   - **안드로이드 폰·태블릿 바탕화면 앱 설치**: 크롬·삼성 인터넷에서 우측 상단 파란색 **`[📲 앱 설치]`** 버튼(또는 팝업 내 **`[📲 이 기기에 앱 바로 설치하기]`** 버튼)을 누르면 보안 경고 없이 바탕화면과 앱 서랍에 **`탁구스코어`** 전용 아이콘이 생성되고 주소창 없는 전체 화면 앱으로 동작합니다.
   - **브라우저별 맞춤형 설치 안내**: 삼성 인터넷·아이폰 Safari 등 자동 설치 팝업을 지원하지 않는 브라우저에서는 기기를 자동 감지해 2단계 메뉴 설치 방법을 안내합니다.
   - **오프라인 실행 & 자동 업데이트(Service Worker)**: 한번 설치하면 인터넷이 없는 환경에서도 실행되며, 향후 UI/UX 수정 후 GitHub에 푸시하면 회원들이 앱을 재설치할 필요 없이 자동으로 최신 버전이 반영됩니다.
   - **회원 공유용 QR코드 내장**: **`[설정] → [📲 앱 설치 및 회원 공유 (QR)]`**을 열면 다른 회원들이 스마트폰 카메라로 찍어서 3초 만에 앱을 설치할 수 있는 QR코드와 주소 복사 버튼이 제공됩니다.

## 3. 📖 사용법 및 앱 설치 안내

### Step 1. 스마트폰/태블릿에 앱으로 설치하기 (또는 단일 HTML 실행)
- **방법 A: 설치형 웹앱(PWA)으로 설치 (추천)**
  1. 스마트폰/태블릿에서 **`https://swmin.github.io/pingpong-club/`** 에 접속하거나, 먼저 설치한 회원의 **`[📲 앱 설치]`** 화면에 있는 QR코드를 카메라로 스캔합니다.
  2. 화면 우측 상단(`설정` 왼쪽)의 파란색 **`[📲 앱 설치]`** 버튼을 누른 뒤 **`[📲 이 기기에 앱 바로 설치하기]`**를 선택하면 바탕화면에 **`탁구스코어`** 앱 아이콘이 설치됩니다.
  3. 만약 삼성 인터넷이나 아이폰(Safari)을 사용 중이라면 팝업 안내에 따라 브라우저 메뉴(**삼성 인터넷**: 하단 `[ ≡ ]` ➔ `[+ 현재 페이지 추가]` ➔ `[홈 화면]` / **크롬**: 우측 상단 `[ ⋮ ]` ➔ `[앱 설치]` 또는 `[홈 화면에 추가]`)를 눌러 설치할 수 있습니다.
- **방법 B: 단일 파일(`pingpong-club-scoreboard.html`)로 직접 실행**
  - 다운로드받은 `pingpong-club-scoreboard.html` 파일을 크롬(Chrome), 삼성 인터넷, 사파리(Safari) 등으로 바로 열어도 100% 동일하게 동작합니다.

### Step 2. 동호회 및 모임 날짜 선택/생성
- 상단 **`[동호회 생성]`** 및 **`[동호회 목록]`** 버튼을 통해 원하는 동호회를 선택하거나 신규 동호회를 생성합니다.
- **`[+ 새 모임 생성]`** 또는 **`[모임 히스토리]`** 버튼을 눌러 오늘 모임 날짜 페이지를 새로 만듭니다.

### Step 3. 오늘의 참가 선수 선택
- **`[선수 선택/등록 메뉴]`**를 열어 **`🏢 동호회 선수`** 또는 **`⭐ Guest 선수`** 탭에서 오늘 출전한 선수를 클릭하여 참가자로 지정합니다.
- 선수의 당일 부수를 변경하고 싶을 경우 이름 옆의 부수 선택창을 눌러 변경합니다.

### Step 4. 경기 결과 입력 (3가지 뷰 중 편한 방식 선택)
- **`👤 선수별 보기`** (스마트폰 기본): 선수 카드를 터치해 펼친 뒤, 상대 선수 행의 **`[점수 입력]`** 버튼(또는 기존 점수)을 터치합니다.
- **`📋 경기 순서별`**: 라운드 순서대로 나열된 경기 카드를 터치합니다.
- **`🏁 격자표`** (태블릿/PC 기본): 종이 대진표 형태의 교차 셀을 터치합니다.
- 점수 입력 팝업창에서 승리 세트 수(예: `2:0`, `2:1` 등)를 선택하고 **`[점수 저장]`**을 누르면 모든 대진표 뷰와 순위표에 즉시 반영됩니다.

### Step 5. 여러 명 폰/태블릿으로 점수 함께 입력하기 (`📡 함께 입력하기`)
1. **방 만들기 (방장 폰/태블릿)**: 선수 명단 아래의 **`[📡 함께 입력하기]`** 버튼을 누른 뒤 **`[방 만들기]`**를 누르면 **방 번호 4자리**, **참가용 QR코드**, **관리자 번호 4자리**가 화면에 나타납니다.
2. **방 참가하기 (도우미 회원 폰)**: 도와줄 회원들은 자기 폰에서 앱을 열고 **`[📡 함께 입력하기]`**를 눌러 내 이름을 적고 **4자리 방 번호를 입력**하거나 **`[QR 스캔]`**으로 방장 화면의 QR코드를 비춥니다.
3. **공동 점수 입력**: 연결되는 즉시 방장의 오늘 모임 대진표가 도우미 폰에 그대로 나타나며, 누구든 점수를 입력하면 방장·관리자·도우미 전원의 화면과 순위표가 실시간으로 똑같이 갱신됩니다.
4. **공동 관리자 지정 (선수 추가/제외가 필요할 때)**:
   - 방장이 **`[함께 입력하기]`** 창의 접속자 목록에서 해당 회원 옆 **`[👑 관리자 주기]`**를 누르거나,
   - 도우미 회원이 자기 폰의 **`[🔓 관리자 번호 입력]`**을 눌러 방장 화면의 **관리자 번호 4자리**를 입력하면 선수 명단 수정 권한이 열립니다.
5. **총무님이 불참하는 날의 활용 팁**:
   - 그날 참석한 임원 중 한 분이 자기 폰에서 **`[방 만들기]`**를 누르면 그분이 일일 방장이 됩니다.
   - 불참하신 총무님도 집이나 외부에서 카톡으로 전달받은 **4자리 방 번호**로 접속하면 실시간으로 경기 진행 상황을 볼 수 있고, 그날의 모임 기록과 선수 명단이 내 폰에도 자동으로 똑같이 저장됩니다.

### Step 6. 실시간 및 통산 순위 확인
- 하단 **`🏆 오늘 모임 실시간 순위표`** 탭에서 오늘 모임의 실시간 순위 및 득실 세트, 동률 규정 사유를 확인합니다. (모바일에서는 **`[동률 사유 ▾]`** 배지를 터치하면 상세 사유가 펼쳐집니다.)
- **`📊 동호회 통산 누적 순위표`** 탭을 클릭하여 전체 모임 기록이 누적 합산된 통산 순위를 확인합니다.

### Step 7. 이미지 저장 및 기기 간 백업/동기화
- **`[결과저장]`** 버튼을 클릭하면 화면 방향(가로/세로)과 관계없이 전체 대진표와 순위표가 한 장의 고화질 PNG 이미지로 기기의 `Download` 폴더에 저장됩니다.
- **`[📂 데이터 포함 HTML 저장]`** 버튼을 눌러 저장된 HTML 파일을 원드라이브(OneDrive)에 올려두거나 **`[백업 (.json)]`** 파일을 활용하면 휴대폰이나 갤럭시 탭에서도 100% 동일하게 모임 기록을 이어서 사용할 수 있습니다.
